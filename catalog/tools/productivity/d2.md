# D2

D2 genera diagramas declarativos desde texto. Es útil para que un mapa de sistema AI, sus flujos de datos y sus límites de confianza vivan junto al código y puedan revisarse en una MR.

## Uso diario

Crea un diagrama de routing mínimo:

```d2
user: Usuario
api: API
router: Model router
fast: Modelo rápido
strong: Modelo de mayor capacidad
evals: Evaluation gate

user -> api -> router
router -> fast: tarea sencilla
router -> strong: tarea compleja
evals -> router: métricas y regresiones
```

Renderízalo como SVG, que se puede versionar y leer en GitHub:

```sh
d2 docs/architecture/model-routing.d2 docs/architecture/model-routing.svg
```

El diagrama debe declarar propietarios, datos sensibles y controles cuando sea relevante; no es decoración. Actualízalo al cambiar una frontera, un proveedor, una herramienta MCP o el flujo de datos.

## Combinado con

- [OpenSpec](../ai/openspec.md): adjunta el diagrama al cambio antes de implementar una integración de alcance relevante.
- [OpenTofu](../platform/opentofu.md): enlaza recursos reales de infraestructura con el flujo lógico, sin intentar reemplazar IaC por un dibujo.
- [Stern](../platform/stern.md): contrasta el flujo esperado con el comportamiento que observas en producción.
