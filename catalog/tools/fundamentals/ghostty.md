# Ghostty

**Qué resuelve:** emulador de terminal nativo para macOS donde se ejecutan Zsh, Herdr y los agentes.

## Uso diario

```sh
ghostty --version
open -a Ghostty
```

Configura fuentes, tema y atajos en la configuración de Ghostty; evita incluir tokens, rutas sensibles o comandos que peguen secretos en perfiles compartidos.

## Combinado con

Abre Ghostty y usa Herdr desde el directorio del proyecto para conservar sesiones de agentes:

```sh
cd <proyecto>
herdr
```

Fuente: [Ghostty Documentation](https://ghostty.org/docs).
