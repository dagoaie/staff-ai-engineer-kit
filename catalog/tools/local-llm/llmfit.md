# llmfit

**Qué resuelve:** recomienda modelos y cuantizaciones según el hardware disponible.

## Uso diario

```sh
llmfit
llmfit --help
llmfit --version
```

Una recomendación no sustituye validar latencia, calidad, consumo y licencia sobre tu carga real.

## Combinado con

Usa la recomendación para decidir qué cargar en [LM Studio](lm-studio.md), y mide después con un conjunto de [Promptfoo](../ai/promptfoo.md):

```sh
llmfit
promptfoo eval
```
